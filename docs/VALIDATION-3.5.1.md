# 3.5.1 · Проверка мессенджеров отключена

По уточнению заказчика удалены ручные отметки наличия Telegram/Viber, поля форм, кнопка настройки и скрытие иконок по этим отметкам. Проверки контакта/ЛПР и запреты обращения сохранены.

Иконки Telegram и Viber — обычные ссылки у распознанного международного номера. Наличие аккаунта не проверяется ни автоматически, ни вручную через CRM. Старые отметки «Не найден» больше не скрывают ссылки. Отметка ранее открытой ссылки остаётся самостоятельным локальным признаком.

В копируемой карточке больше нет сведений о наличии аккаунтов. История прежних действий не переписывается. Улучшенные таблицы и текстовое копирование без JSON сохранены.

Опубликованная миграция 0016 и её поля оставлены исключительно для совместимости установленных баз и резервных копий 3.5. В приложении и административной форме эти поля не используются. Дополнительных миграций нет, данные не удаляются.

Проверено: 104 Django-теста на SQLite — 103 успешно, 1 требует PostgreSQL. Регрессии покрывают обе ссылки даже при старых отметках «absent», отсутствие настроек/полей в таблице, карточке и формах, игнорирование устаревших POST-параметров, отсутствие отметок в копируемом тексте и скрытие полей административной формы. `makemigrations --check --dry-run`: без изменений. `collectstatic`: успешно.

После обновления файлов приложения перезапустите программу и нажмите Ctrl+F5. Предварительно сохраните резервную копию обычным способом.
