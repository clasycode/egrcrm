# 3.7.1 — WinError 32 при запуске Windows

Причина: контекстный менеджер `sqlite3.Connection` завершает транзакцию, но не закрывает соединение. Временная SQLite-копия оставалась открытой при переименовании и удалении, что Windows отклоняет с WinError 32. Ошибка относится к временному файлу резервирования, а не к повреждению основной базы.

Исправлено явное закрытие обоих SQLite-соединений через `contextlib.closing` до переименования/очистки. Исправление также применено к прежнему скрипту `prepare_local.py`. Нет новых миграций и изменений пользовательских данных.

Регрессионные проверки проверяют, что оба соединения закрыты до переименования; читаемость успешной копии; закрытие до удаления временного файла при ошибке; сохранность исходной базы и отсутствие незавершённой копии после ошибки. Проверки выполнялись на Linux с явной проверкой закрытых соединений, нативная Windows здесь не запускалась.

## Как продолжить

1. Закройте окно CRM с ошибкой кнопкой «Остановить и закрыть», дождитесь закрытия.
2. Скачайте исправленную версию с GitHub и распакуйте полностью в новую папку.
3. Нажмите «Запустить CRM.bat». Будут использованы прежняя база и логин в AppData.

Не удаляйте `%LOCALAPPDATA%\RudyCortex\EGRCRM`, `dev.sqlite3` или `.local-key`. Удаление оставшегося `.copy-….sqlite3` не требуется для повторного запуска: каждая попытка создаёт уникальное имя.
