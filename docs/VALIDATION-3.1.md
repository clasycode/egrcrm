# Проверка интерфейса 3.1

Дата: 05.11.2026. Среда: Python 3.12, Django 5.2, SQLite, Chromium/Linux. Сборщик в превью выключен, источник на паузе, данные вымышленные в отдельной временной базе.

- `manage.py test`: 82 проверки, 81 успешно, 1 пропущена (требует PostgreSQL для проверки конкурентных блокировок).
- `manage.py makemigrations --check --dry-run`: изменений моделей нет.
- Chromium: вход, список, расширенные фильтры, выбор строк, панель массовых действий, диалоги карточки, просроченные задачи.
- Все 10 дополнительных адресов открываются с HTTP 200: сбор (3 вкладки), копии, подборки, статистика, настройки, кандидаты, история, диагностика.
- Проверены уникальность DOM id на этих экранах и отсутствие ошибок JavaScript.
- На ширине 360 и 390 px нет горизонтального переполнения документа. Широкие таблицы имеют собственную прокрутку.
- Экспорт выбранной строки скачан и прочитан: в CSV есть выбранный УНП, отсутствует УНП соседней строки.
- Проверены Escape, мобильное меню и смена ширины с открытого мобильного меню на десктоп: основное содержимое снова доступно для фокуса и взаимодействия.
- Тесты защищают экранирование пользовательских статусов, устойчивость знака компании, сохранение фильтров, отдельный экран входа и уникальные идентификаторы полей карточки.
