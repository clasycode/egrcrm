# Доработки после аудита — 3.0

Исторический аудит относился к a5a3663. В 3.0 реализованы его рабочие пункты:

| Область | Изменение | Проверка |
|---|---|---|
| Сохранность | Только поля источника + блокировки строк, единый порядок блокировок UI/импорт | Последовательные тесты и конкурентный тест PostgreSQL |
| Обновления/перенос | AppData отдельно от программы, native SQLite-копия перед миграцией, версионный ZIP, атомарное восстановление и страховочная копия | Повторный запуск prepare_local сохраняет новые записи; round-trip и повреждённые архивы, FK и роли |
| Сбор | Единая UI/CLI-очередь, изоляция ошибочных кандидатов, 3 ограниченные попытки с задержкой, пауза/сброс | Ошибка одного кандидата не мешает следующему; сброс во время HTTP не воскресит задание |
| Дозагрузка | Отдельные запуски, повтор контактов через 7/30 дней, покрытие дней простоя | Проверки календаря, этапов повтора, истории запуска |
| Источник | Снимки всех изменившихся ответов, адресов/контактов; уведомление об изменениях, исходные строки | История и сохранность ручной работы |
| Поиск/фильтры | Unicode casefold и контакты, география, состояние ЕГР, задачи/проверки/ответственный, актуальность без выбора типа | Фильтры и прежние регрессии |
| UX | Разделены новый сбор/прогресс/расписание; живые счётчики, таблица компаний, страница УНП; сохранение выбора при автообновлении | HTTP-проверки и синтаксис JS; непосредственная визуальная проверка Windows остаётся у заказчика |
| Работа CRM | Задачи, ответственные, журнал обращений/ответов, читаемая лента, ручные контакты и проверки, запреты, статусы | Сквозные CRUD-проверки, роли и ограничения |
| Выборки | Сохранённые фильтры, строки/весь фильтр, массовые действия, CSV/XLSX и разрешённые заметки | Строки и формулы, текстовый XLSX, частичный экспорт без остановки сбора |
| Отчётность | Показатели базы отдельно от реальных событий, конверсии с знаменателями, география/ОКЭД/возраст/тип, задачи | Импорт/заметки не считаются обращением; определения показаны в UI |
| Эксплуатация | Версия/диагностика, ограничение входа, роли, контейнер/Gunicorn/PostgreSQL/worker, HTTPS-пример, ежедневные/внешние копии | Образ собран; тесты PostgreSQL; финальная проверка на целевом сервере обязательна |
| Производительность | Опрос прогресса кратко кешируется, CSV порциями, XLSX во временный файл; обновление счётчиков запусков ограничено по частоте | Проверки экспорта и функциональности; промышленный нагрузочный замер не проведён |
| Сайт | Ручная очередь Brave, состояния не настроено/ошибка/нет результатов/нужна проверка/подтверждено | Отсутствие ключа и внутренние URL проверены; реальный платный провайдер требует ключа заказчика |

Непроверенные внешние условия не подменяются проходящими тестами: production-доступ ЕГР, независимое расписание на будущем сервере, домен/сертификат, внешний диск и живой поисковый тариф должны быть проверены при размещении. Пакетное ускорение не включается без сопоставления ответов: для него есть отдельная диагностическая команда.
