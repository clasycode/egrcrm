# Версия 3.6 — локальная CRM для Windows

## Что изменилось

- `Запустить CRM.bat` / `start-windows.bat` открывают окно управления RudyCortex. Первая подготовка устанавливает зависимости, создаёт владельца и автоматически открывает браузер. Повторные запуски используют подготовленную среду.
- Кнопки: открыть CRM, переносимая резервная копия, восстановить пароль владельца, журналы, папка данных, остановить и закрыть.
- Waitress вместо сервера разработки, два потока, только `127.0.0.1:8000`; отдельный сборщик. Обычный серверный HTTPS-режим сохраняется, локальный HTTP включается отдельной переменной. CSRF и вход остаются обязательными.
- Файловая блокировка запрещает второй экземпляр с той же базой. Остановка отменяет текущий запрос между сетевыми шагами, возвращает задание в очередь и освобождает lease. Windows Job Object завершает дочерние процессы при аварийном выходе окна.
- Данные и среда Python живут в AppData отдельно от исходников. Старая база переносится только копированием, существующая не заменяется; до миграций создаётся SQLite-копия. Новых миграций моделей нет.
- Существующий переносимый ZIP остаётся способом будущего перехода на сервер, включая PostgreSQL. Серверный пакет включает общие вспомогательные модули.

## Проверка

- Django: 113 тестов на SQLite, 112 успешно, один тест конкурентного доступа требует PostgreSQL и пропущен. Новые проверки включают сохранение прежней базы/ключа, блокировку второго экземпляра, создание и восстановление владельца, CSRF, изоляцию серверных настроек HTTPS, отмену зависшей подготовки и возврат задания в очередь без расходования повторов.
- Установщик/упаковка: 4 теста успешно.
- Интеграционный запуск в Linux: новая изолированная база, миграции, создание владельца, collectstatic, реальные Waitress + worker, вход через HTTP с CSRF/cookies, переносимый ZIP, штатная остановка, смена пароля и повторный запуск с той же базой. Сборщик был приостановлен; запросы к ЕГР не выполнялись.
- Проверены синтаксис Python, Django system check и отсутствие новых миграций.

Нативное окно Tkinter, BAT, Python Launcher и Windows Job Object требуют проверки на Windows 10: в доступной среде Linux их выполнение не подтверждено. Проверки не подтверждают текущую доступность ЕГР с компьютера пользователя. Отдельный установщик EXE не создавался: требуется Python 3.12 с Tcl/Tk.
